## 💻 Sobre o Projeto

O **Meu Controle Financeiro** é uma aplicação web voltada para a gestão de finanças pessoais, permitindo que o usuário cadastre suas entradas (rendas) e saídas (despesas) de forma simples. O projeto foi desenvolvido como parte de uma experiência prática da faculdade, focando em criar uma interface altamente dinâmica e responsiva sem depender de frameworks complexos.

## ⚙️ Funcionalidades

- **Controle de Saldo:** Cálculo automático e reativo de entradas, saídas e saldo disponível.
- **Histórico de Movimentações:** Listagem de todas as transações com diferenciação visual entre rendas e despesas.
- **Filtros Avançados:** Opção para visualizar "Todos", apenas "Rendas" ou apenas "Despesas".
- **Persistência de Dados:** Uso de armazenamento local para que os dados não sumam ao fechar ou recarregar a página.
- **Limpeza Total:** Opção para apagar todo o histórico de transações com confirmação de segurança.
- **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e computadores usando múltiplas media queries.

## 🛠 Tecnologias

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização avançada com Flexbox e Media Queries)
- **JavaScript** (Lógica nativa e manipulação do DOM)

## 🧠 O que pratiquei

- **Manipulação Avançada do DOM:** Criação dinâmica de elementos com `document.createElement()`, `appendChild()` e limpeza de contêineres com `innerHTML`.
- **Template Literals:** Uso prático de crases e `${}` para injeção limpa de estruturas HTML via JavaScript.
- **Eventos Nativos:** Interceptação de interações de fluxo e controle de modais usando `addEventListener` e `classList`.
- **Controle de Formulários:** Uso do `e.preventDefault()` para travar o comportamento padrão de atualização do navegador e validação preventiva de inputs (`trim`, `isNaN`, etc.).
- **Persistência com LocalStorage:** Serialização e desserialização de arrays e objetos utilizando `JSON.stringify()` e `JSON.parse()`.

## 🔀 Versionamento e GitFlow

Um dos grandes marcos deste projeto foi o aprendizado prático sobre **Versionamento de Código**. Utilizando o fluxo do **GitFlow**, pude sair da teoria e aprender a gerenciar branches de forma profissional diretamente no GitHub. 
- O desenvolvimento da responsividade foi isolado de maneira segura na ramificação `feature/responsividade`.
- As alterações foram integradas à linha do tempo principal de testes através de Pull Requests para a branch `develop`.
- Por fim, o código foi unificado via merge para a branch `main`, mantendo o histórico de produção limpo e estável.
